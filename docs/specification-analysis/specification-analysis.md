# Анализ спецификации — simpleSketchFlow

## Суть проекта

TypeScript-приложение, которое рендерит Pixi.js сцену через Skia (CanvasKit WASM), поддерживает интерактивность и экспортирует векторный PDF через Skia PDF backend.

**Ключевая сложность:** нужно написать мост между Pixi.js и Skia — обходной путь, потому что Pixi рендерит через WebGL/Canvas2D, а Skia через свой WASM-движок. Нужно извлечь данные из Pixi-дерева и отрисовать их средствами Skia.

---

## Шаги к выполнению

### Этап 1 — Подготовка проекта

1. Инициализация проекта (TypeScript, bundler, dev-сервер)
2. Установка зависимостей: `pixi.js@7.2.4-legacy`, `canvaskit-wasm`
3. Настройка двух canvas-элементов в HTML
4. Базовая структура: кнопки "Сгенерировать" и "Экспорт PDF"

### Этап 2 — Pixi.js сцена

5. Создание `PIXI.Application` с `forceCanvas=true`
6. Реализация генератора случайных фигур (Graphics: rect, ellipse, line)
7. Поддержка трансформаций: position, angle, scale
8. Вложенность контейнеров (Container → Container → Graphics)

### Этап 3 — Skia обёртка (ядро задачи)

9. Загрузка CanvasKit WASM
10. Реализация `convertPixiContainerToSkia()` — обход дерева Pixi
11. Маппинг `PIXI.Graphics` → Skia-операции (drawRect, drawEllipse, drawLine)
12. Обработка трансформаций: матрицы преобразования Pixi → Skia
13. Поддержка fill, stroke, lineStyle
14. Отрисовка на втором canvas через Skia Surface

### Этап 4 — Экспорт PDF

15. Создание Skia PDF Document
16. Повторная отрисовка сцены в PDF canvas
17. Скачивание готового PDF-файла

### Этап 5 — Интерактивность

18. Реализация pointerDown / pointerUp на Pixi-объектах
19. Синхронизация событий между двумя canvas (координатный маппинг)

### Этап 6 — Финализация

20. UI-полировка, README, инструкция запуска
21. Деплой на бесплатный хостинг (GitHub Pages / Vercel / Netlify)
22. Тестирование, исправление багов
